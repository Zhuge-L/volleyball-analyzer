# 教学示范视频

把各项目示范录像放到本目录，文件名与项目 id 一致，即可在项目页自动播放：

| 文件 | 项目 |
| --- | --- |
| `selfBump.mp4` | 自垫球 |
| `tossBump.mp4` | 抛–垫球 |
| `selfSet.mp4` | 自传球 |
| `tossSet.mp4` | 抛–传球 |
| `overhand.mp4` | 上手发球 |
| `underhand.mp4` | 正面下手发球 |
| `spike.mp4` | 扣球 |

建议：固定机位、全身入镜、10～20 秒、H.264 / MP4。未上传时页面显示占位，不影响分析功能。

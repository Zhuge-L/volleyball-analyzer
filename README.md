# 🏐 VolleySense · 北京大学排球课程智能分析

本程序专门为**北京大学排球课程**研发，用于课堂与课后的考试视频自评。
学生登录后选择考试项目，上传视频，系统基于 **MediaPipe Pose** 在浏览器本地识别人体 33 个关键点，
按项目对照技术要点给出关键帧评分与改进建议。报告可导出交给任课教师。

> 纯静态网页，无需后端。视频不上传任何服务器。
> **不检测排球本身**——画面上的「击球动作」是根据人体运动推算的相位，无球空挥也可能被标出。

## 考试项目

| 项目 | 评分重点 | 建议机位 |
| --- | --- | --- |
| 垫球 | 击球平台（伸直 / 对称 / 倾角）+ 下肢蹲深 + 躯干 | 斜侧面 30°～45° |
| 传球 | 额前手型、两手间距、传球肘角 | 正面或斜正面 20°～30° |
| 下手发球 | 腰腹以下击球点、挥臂伸直 | 击球臂一侧正侧面 |
| 上手发球 | 头上最高点击球、击球臂伸直 | 击球臂一侧斜侧面 30° |
| 扣球 | 起跳腾空、头上击球、击球臂伸直 | 击球臂一侧斜侧面，镜头拉远 |

通用取景：固定机位、全身入镜、头顶留空、先自然站直 1～2 秒再开始动作。画面中只保留一名学生。

## 功能

- 登录（姓名 + 学号，仅保存在本机浏览器）
- 五项考试技术分模块分析与报告
- 站立段不计分；击球相位由人体动作推算（非球体检测），并已提高触发门槛
- 低置信度关键点自动降权
- 「当前重点」提示：最该改的一项 + 可执行差值
- 训练档案与近几次成绩趋势
- 导出 PDF 报告：单项考试报告 / 全部项目总报告
- 0.25× / 0.5× 慢放；移动端适配

## 本地预览

```bash
python -m http.server 8000
```

浏览器打开 http://localhost:8000 （不要直接双击 html）。

评判标准在 `js/skills.js`，可按课堂要求调整。
